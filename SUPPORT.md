# Getting help

| Need | Where |
| --- | --- |
| Questions about using or designing the skill | [Discussions → Q&A](https://github.com/loriamichaelj/terraform-landing-zone-agent-skill/discussions/categories/q-a) |
| Ideas and early proposals | [Discussions → Ideas](https://github.com/loriamichaelj/terraform-landing-zone-agent-skill/discussions/categories/ideas) |
| Something is broken | [Open a bug report](https://github.com/loriamichaelj/terraform-landing-zone-agent-skill/issues/new/choose) |
| A security problem | Report it privately, as described in [SECURITY.md](SECURITY.md) |

Before asking, check the [README](README.md) and the [skill package](.agents/skills/landing-zone/SKILL.md).

This is a volunteer-maintained project; there's no paid support or response-time guarantee. When you share specs or logs, redact org IDs, billing accounts, CIDR plans and email addresses.
